# Advantage_dev — Personal Portfolio

> Creating Web Experience That Drives Results.

A responsive, animated personal portfolio built to showcase my work, skills, and process as a Web developer.

**🔗 Live site:** [Ojekunle David-JOY Portfolio](https://ojekunledavidjoy-portfolio.vercel.app/)

---

## ✨ Features

- **Fully responsive** — mobile, tablet, and desktop layouts for every section
- **Light / dark mode** toggle, synced across the whole site
- **Scroll-triggered animations** (Framer Motion) — sections and cards fade/slide in independently as they enter view
- **Active nav-link tracking** — the navbar underlines whichever section you're currently scrolled through
- **Smooth-scroll navigation** with a sticky navbar and a "back to top" button
- **Animated tech-stack showcase** in the About section
- **Direct WhatsApp integration** for the fastest way to get in touch
- **Contact form** for project inquiries
- **Ongoing vs. completed project badges** on the Projects section, with disabled "Coming Soon" states for work still in progress

## 🧩 Sections

| Section | Description |
|---|---|
| **Hero** | Introduction, availability status, and primary calls to action |
| **About** | Bio, tools I use, and quick stats (projects shipped, years building, Lighthouse score) |
| **Services** | What I offer — web development, landing pages, UI implementation, redesigns, maintenance |
| **How I Work** | My process, broken into clear stages from discovery to deployment |
| **Projects** | Case studies of shipped work, with live demo links and tech stack tags |
| **From the Build** | Behind-the-scenes updates, lessons learned, and what I'm currently working on |
| **FAQ** | Common questions before starting a project |
| **Contact** | Form, WhatsApp, location, and availability |

## 🛠️ Built With

- **React.js** + **Vite**
- **Tailwind CSS**
